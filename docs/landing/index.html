An immune system for AI-generated code

What it does

Secret & risk scanning

Deterministic detectors catch leaked credentials and risky patterns and mask them before any LLM tier sees the diff.

Three-tier cost gate

Cache → local model → premium dual-model consensus (Claude Sonnet 4.6 + Gemini). You pay for deep review only on real risk.

Merge gating

Commit statuses and PR comments block risky changes — run shadow-mode first, then flip to enforcement when you trust it.

MCP & package firewall

Governs agent tool calls, blocks typosquatted dependencies, and discovers shadow-AI usage across your org.

Runs everywhere

Static CLI, IDE extension, and multi-arch containers — SaaS, private VPC, or fully air-gapped.

Observable & provable

Distributed tracing, metrics, an audit trail, and a measured accuracy SLO (precision / recall / false-positive rate).
